# 🎯 Next 10 Practice Questions

* Before recursion, I'd like you to solve these:

1. Return the smaller of two numbers.
2. Return the largest of three numbers.
3. Return the factorial (using a normal loop, not recursion).
4. Return the sum of digits of a number.
5. Return the reverse of a number.
6. Return whether a year is a leap year.
7. Return the area of a circle.
8. Return the simple interest.
9. Return whether a string is a palindrome.
10. Create one function that calls another function.

If you can solve these comfortably, you'll have a solid foundation for recursion.
