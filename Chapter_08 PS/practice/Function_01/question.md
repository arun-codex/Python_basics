# Level 1 (No return)
1. Create a function that prints "Hello World".
2. Create a function that prints your name.
3. Create a function that prints "Good Morning".
4. Create a function that prints numbers 1–5.
5. Create a function that prints a multiplication table of 5.
# Level 2 (Parameters)
6. Create a function that prints "Hello <name>".
7. Create a function that prints the square of a number.
8. Create a function that prints the cube of a number.
9. Create a function that prints the larger of two numbers.
10. Create a function that prints whether a number is even or odd.
# Level 3 (return)
11. Return the square.
12. Return the cube.
13. Return the larger number.
14. Return the average of two numbers.
15. Return whether a number is prime.
