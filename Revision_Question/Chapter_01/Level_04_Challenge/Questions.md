# Chapter 01 — Level 04: Challenge

## Challenge Set

1. Build a small Random Number Analyzer that generates a random integer from 1–100, calculates its square root, prints both values, and explains the result with a comment.
2. Create a program that accepts a number and prints the number, its square root, its ceiling, and its floor.
3. Explain, without running code, why this prints a value:

    import math
    x = math.sqrt(144)
    print(x)

Then modify it so the result is stored and reused twice.
4. A teammate says: “I installed requests, so now Python automatically runs it.” Correct the statement and explain installation versus importing.
5. Design a troubleshooting checklist for: ModuleNotFoundError: No module named 'requests'.
6. Write a program using random and math that could be useful in a cybersecurity training lab, such as generating a random test value and calculating a related mathematical value.
7. Without executing it, predict the type and output behavior of:

    import math
    value = math.sqrt(50)
    print(type(value))
    print(value)

8. Explain why this distinction matters: function returns a value ≠ function automatically prints the value.
9. Create your own example demonstrating importing a module, calling a function, and printing a returned value.
10. Final challenge: Teach Chapter 01 to a beginner in five minutes using five examples. Include import, pip install, module, function, and comments.
