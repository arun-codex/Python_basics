# Chapter 01 — Level 02: Intermediate

## Modules, Comments & pip

1. Write a program that imports math and calculates the square root of a number entered by the user.
2. Write a program that uses math.ceil() and math.floor() on the same decimal number.
3. Import random and generate a random integer between 1 and 10.
4. Explain why this works:

    import math
    answer = math.sqrt(81)
    print(answer)

5. Explain what is wrong with:

    import sqrt

6. Write a short program containing three useful comments and explain why each comment is useful.
7. A student writes: pip install math. Should they normally do this for Python's standard-library math module? Explain.
8. Write a program that imports both math and random and uses one function from each.
9. Predict the result and type of x:

    import math
    x = math.sqrt(49)
    print(x)

10. Explain the sequence when a program uses an external package: install package → import package → use its functions/classes.
