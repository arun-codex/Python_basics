# 🧠 Python Revision Question Bank

Revision questions are organized **Chapter → Level**.

## 📂 Structure
```text
Revision_Question/
├── Chapter_01/
│   ├── Level_01_Basic/
│   ├── Level_02_Intermediate/
│   ├── Level_03_Advanced/
│   └── Level_04_Challenge/
├── Chapter_02/
├── Chapter_03/
├── ...
├── Chapter_13/
└── Loop_Revision/
```

## 🎯 Difficulty Levels

| Level | Purpose |
|---|---|
| Level 01 — Basic | Recall syntax and fundamental concepts |
| Level 02 — Intermediate | Apply concepts and write small programs |
| Level 03 — Advanced | Combine concepts, debug, and reason about code |
| Level 04 — Challenge | Problem-solving and cybersecurity-style thinking |

## 🔄 Revision Rule

1. Complete Level 01.
2. Check mistakes.
3. Move to Level 02.
4. Continue only when the previous level is understood.
5. Record weak areas in docs/summary.md.

Existing specialized revision material such as Loop_Revision/ is preserved.
