---

**Question:** What does the `open()` function return?
<details>
<summary>Answer</summary>
A file object that allows you to perform read, write, or append operations on the file.
</details>

---

**Question:** What is the default mode of the `open()` function?
<details>
<summary>Answer</summary>
Read mode (`"r"`).
</details>

---

**Question:** Which file mode is used to add text to the end of an existing file?
<details>
<summary>Answer</summary>
Append mode (`"a"`).
</details>

---

**Question:** Why is it recommended to use the `with` statement when opening files?
<details>
<summary>Answer</summary>
It automatically closes the file when the block of code exits, preventing resource leaks and ensuring data is properly saved.
</details>

---

**Question:** What is the difference between `readline()` and `readlines()`?
<details>
<summary>Answer</summary>
`readline()` reads a single line as a string. `readlines()` reads all lines and returns them as a list of strings.
</details>
