# The Perfect Guess

* We are going to write a program that generates a random number and asks the user to guess it.
* If the playerʼs guess is higher than the actual number, the program displays “Lower number please” .
* Similarly, if the userʼs guess is too low, the program prints “Higher number please” . When the user guesses the correct number, the program displays the number of guesses the player used to arrive at the number.
